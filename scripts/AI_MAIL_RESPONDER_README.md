# AI Mail Responder

The AI Mail Responder monitors an IMAP mailbox and sends controlled auto-replies to a whitelist of senders. The first reply is generated by OpenAI and includes a universal license key (appended by the script so the AI never sees it). The second reply within 24 hours is a fixed template; after that, no further replies are sent for that sender.

## Behaviour (per sender)

| When | Action |
|------|--------|
| **First email ever** | Send AI-generated reply + universal license key in footer. |
| **Second email within 24h of first** | Send fixed template: "Thanks for following up. I'm currently looking into this..." |
| **Third email, or any email after 24h of first** | No reply (conversation is permanently closed for that sender). |

Only senders in the **allowed senders** list receive any reply. All others are ignored.

## Requirements

- Python 3.11+
- `openai` package: `pip install openai`
- IMAP (incoming) and SMTP (outgoing) access to the mailbox
- Environment variables set (see below)

## Configuration

Configuration is in `ai_responder_config.py`. Secrets and key options should be set via **environment variables** so they are not stored in the repo.

### Required environment variables

| Variable | Description |
|---------|-------------|
| `AI_RESPONDER_MAILBOX_PASS` | Password for the mailbox (IMAP and SMTP). |
| `AI_RESPONDER_OPENAI_API_KEY` | OpenAI API key for generating first replies. |

### License key (first reply)

Set **one** of:

| Variable | Description |
|---------|-------------|
| `AI_RESPONDER_UNIVERSAL_LICENSE_KEY` | The full license key string to append to the first reply. |
| `AI_RESPONDER_UNIVERSAL_LICENSE_KEY_FILE` | Path to a file whose contents are the license key (one line). |

If neither is set, the first reply is still sent but the "Universal License Key" section in the footer will be empty.

### Optional environment variables

| Variable | Default | Description |
|----------|---------|-------------|
| `AI_RESPONDER_MAILBOX_USER` | `marilin.rojas@moviolabs.com` | Mailbox email address. |
| `AI_RESPONDER_IMAP_HOST` | `mail.moviolabs.com` | IMAP server hostname. |
| `AI_RESPONDER_IMAP_PORT` | `993` | IMAP port (SSL). |
| `AI_RESPONDER_IMAP_FOLDER` | `INBOX` | IMAP folder to monitor. |
| `AI_RESPONDER_SMTP_HOST` | `mail.moviolabs.com` | SMTP server hostname. |

| `AI_RESPONDER_DB_NAME` | `ai_mail_state.db` | SQLite state file name (under `scripts/`). |

| `AI_RESPONDER_LOG_LEVEL` | `INFO` | Log level: DEBUG, INFO, WARNING, ERROR. |

## Usage

### Run once (foreground)

From the project root or from `scripts/`:

```bash
# From repo root
export AI_RESPONDER_MAILBOX_PASS="your_password"
export AI_RESPONDER_OPENAI_API_KEY="sk-..."
export AI_RESPONDER_UNIVERSAL_LICENSE_KEY="your_base64_license_key"

python scripts/ai_mail_responder.py
```

Or from the `scripts` directory:

```bash
cd scripts
set AI_RESPONDER_MAILBOX_PASS=your_password
set AI_RESPONDER_OPENAI_API_KEY=sk-...
set AI_RESPONDER_UNIVERSAL_LICENSE_KEY=your_base64_license_key
python ai_mail_responder.py
```

### Run as a service

Use the service wrapper so the process keeps running and can be stopped cleanly:

```bash
python scripts/run_ai_responder_service.py
```

Graceful shutdown: send SIGINT (Ctrl+C) or SIGTERM; the script will finish the current poll cycle and exit.

### Windows Task Scheduler

1. Create a new task (e.g. "AI Mail Responder").
2. Trigger: At startup, or on a schedule.
3. Action: Start a program  
   - Program: `pythonw.exe` or `python.exe`  
   - Arguments: path to `run_ai_responder_service.py`  
   - Start in: path to `scripts` (or repo root).
4. Set environment variables in the task (or in a batch file that sets them and then runs the script).

### Linux systemd

Example unit file, e.g. `/etc/systemd/system/ai-mail-responder.service`:

```ini
[Unit]
Description=AI Mail Responder (MVC Calculator)
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/MVC_CALCULATOR/scripts
Environment=AI_RESPONDER_MAILBOX_PASS=...
Environment=AI_RESPONDER_OPENAI_API_KEY=...
Environment=AI_RESPONDER_UNIVERSAL_LICENSE_KEY=...
ExecStart=/usr/bin/python3 /path/to/MVC_CALCULATOR/scripts/run_ai_responder_service.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Then:

```bash
sudo systemctl daemon-reload
sudo systemctl enable ai-mail-responder
sudo systemctl start ai-mail-responder
```

## Files

| File | Purpose |
|------|--------|
| `ai_responder_config.py` | Configuration and env-based secrets. |
| `ai_responder_utils.py` | Email parsing and IMAP helpers. |
| `ai_mail_responder.py` | Main loop: IMAP poll, decision logic, OpenAI, SMTP send. |
| `run_ai_responder_service.py` | Service entry point (calls `ai_mail_responder.main`). |
| `ai_mail_state.db` | SQLite DB for per-sender state and processed Message-IDs (created at first run). |
| `ai_mail_responder.log` | Log file (created at first run). |

## Security notes

- The **license key is never sent to OpenAI**; it is appended to the first reply in code.
- Store `AI_RESPONDER_MAILBOX_PASS`, `AI_RESPONDER_OPENAI_API_KEY`, and the license key in environment variables or a secure secret store, not in the repo.
- Only whitelisted senders receive replies; all other messages are ignored (and left in the mailbox unless you add a move step).

## Relation to auto-license handler

This responder is separate from the **auto-license email handler** (`auto_license_email_handler.py`), which:

- Targets the @hfmdd.de domain only.
- Generates a **per-email wildcard license** and sends it (no AI).

The AI Mail Responder uses a **single universal license key** and an **allowed-senders whitelist**, and adds an AI-generated first reply. You can run both scripts (e.g. on different mailboxes or the same one with different logic) if needed.
